# JPM Vehículos

Vehicle marketplace for a dealership in Barranquilla, Colombia. Built and
maintained by me since July 2025; the client uses it every day to publish and
sell its inventory.

**Live site: https://jpmvehiculos.com**

## What it does

- Catalog of around 100 vehicles with multi-field filtering and pagination.
- Vehicle detail page with a touch gallery: swipe navigation and a full-screen
  zoom viewer.
- Admin panel behind Supabase Auth and hCaptcha. The client publishes, edits and
  removes vehicles, uploads photos and updates prices without a developer.
- Photos are compressed in the browser before upload, so listings stay fast on
  mobile connections.
- Form validation that warns on suspicious values (year, number of doors, plate
  digit) instead of silently accepting them.
- Direct WhatsApp contact from every listing.
- Additional sections for paperwork, financing, insurance and traffic tickets.

## SEO on a single-page app

A React SPA gives crawlers and link previews an empty shell. This site solves it
without dropping the SPA:

- `vercel.json` matches the user agent and routes **bots only** (Googlebot,
  WhatsApp, Facebook, LinkedIn, Telegram, Bing, and others) to serverless
  handlers in `api/`. Real visitors still get the static app.
- `api/vehiculo.js` renders per-vehicle HTML with Open Graph tags and JSON-LD
  structured data, read live from Supabase. Sharing a car on WhatsApp shows its
  photo, price and specs.
- `api/sitemap.js` builds `/sitemap.xml` dynamically, including a URL for every
  vehicle currently in the database.
- Open Graph images are generated by `scripts/generate-og.mjs`.
- Indexed and monitored through Google Search Console.

## Stack

React · Vite · Tailwind CSS · Supabase (PostgreSQL, Auth, Storage) ·
Vercel (hosting and serverless functions) · hCaptcha · Vercel Analytics

## Project layout

| Path | What it holds |
|---|---|
| `src/App.jsx` | Main application: catalog, filters, detail view, admin logic |
| `src/AdminLogin.jsx`, `src/AdminPanel.jsx` | Authentication and inventory management |
| `src/imageCompression.js` | Browser-side photo compression before upload |
| `api/` | Serverless handlers for bot prerendering and the sitemap |
| `scripts/` | Open Graph image generation, bulk photo compression |
| `supabase.sql` | Tables and row-level security policies |

## Run locally

```bash
npm install
npm run dev
```

## Environment variables

```txt
VITE_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
VITE_HCAPTCHA_SITE_KEY=YOUR_SITE_KEY
```

## Admin

Administrator access uses Supabase Auth. Without the environment variables
configured, the admin panel is not available.
